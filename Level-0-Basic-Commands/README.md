# Level 0 - Basic Linux Commands

## Objective
Practice basic Linux terminal commands and file management.

## Skills Practiced
- Navigating directories using pwd and cd
- Listing files using ls
- Creating directories using mkdir
- Creating files using touch
- Copying files using cp
- Moving and renaming files using mv

## Environment
Linux virtual machine running in VMware Workstation.

## Progress
Beginner Linux command practice.
