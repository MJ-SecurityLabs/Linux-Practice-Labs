# Lab 01 - Linux File Investigation

## Overview
Completed a beginner-level simulated security investigation using Linux commands.

## Objective
Practice file inspection, evidence integrity verification, and security documentation.

## Tools Used
- Linux Terminal
- cat
- stat
- sha256sum
- ls
- Git and GitHub

## Investigation Summary
- Created a simulated failed login log.
- Examined file permissions and metadata.
- Generated and verified a SHA-256 hash.
- Documented findings in an investigation report.

## Findings
The simulated log contained one failed login attempt from 192.0.2.10.

A single failed login does not prove malicious activity.
